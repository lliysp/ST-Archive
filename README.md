# ST-Archive (ST-档案馆)

一个专为SillyTavern定制首页聊天记录归档扩展。

## 档案馆
- **按角色智能折叠**：同一角色的世界线自动归档，默认收起，点击展开。
- **首页深度重构**：去掉原生的“欢迎使用”提示，将首页重绘为中英双语的「CONFIDENTIAL ARCHIVE」档案馆。
- **原生文本清洗**：首页展示剥离历史记录中的HTML标签，仅保留纯文本摘要，不影响真实聊天记录。
- **全主题自适应**：兼容亮色与暗色主题，采用极简等宽英文字体与半透明模糊背景。
- **高级检索与排序**：支持模糊搜索（角色名/标签）、按最近时间/名称正倒序排列。
- **独立置顶系统**：支持角色级置顶，以及单条聊天的置顶高亮（脱离原生状态，独立记录）。
- **分页系统**：每页展示10个角色，底部带极简分页器。
- **收藏跨设备同步**：拾遗收藏、角色置顶、聊天置顶统一保存到酒馆服务器端设置（`extension_settings`），手机和电脑连接同一台酒馆即可共用同一份数据；页面（重新）加载后自动生效。
- **本地备份**：拾遗面板右上角提供「导出 / 导入」按钮，可把全部收藏保存为 JSON 文件，或从备份文件恢复/合并收藏。
- **长文本适配**：详情弹窗限定在屏幕内滚动，超长句子、无空格长串不会再被顶出屏幕。
- **手机视口自适应**：详情弹层按当前“可见视口”定位与限高，手机本地部署、内置浏览器、地址栏伸缩等情况下也不会超出屏幕或看不到顶部。
- **详情弹层置顶**：详情卡片使用浏览器顶层（原生 `<dialog>`），不会被拾遗面板、毛玻璃或任何页面层级盖住。
- **聊天名实时同步**：重命名聊天记录后，拾遗里的来源名字会跟着更新——渲染时现取当前聊天列表里的名字，不再沿用收藏时存下的旧名字。

## 性能（v1.3.0）
- **千楼聊天不卡**：正文书签/划线从“每秒全量扫描”改成“事件驱动 + 只处理可见消息”，并按楼层建索引；收藏再多也不会每秒做几十万次比对。
- **下划线零 DOM**：支持 CSS Highlight API 的浏览器直接用原生高亮绘制，不再往正文里插入几千个 `span`；老浏览器自动降级，仍然只处理可见消息。
- **首页档案馆按页/按批渲染**：一页只建 10 个角色组，组里的聊天行展开时才按 80 条一批补；屏幕外的档案行不参与排版。
- **拾遗面板分批渲染**：【当前聊天】先建 40 张卡片，滚到底再补；【全部聊天】只建分组标题，点开哪组才建哪组的卡片。删除单张卡片不再重排整个面板。
- **手机滚动更顺**：移除了 document 上常驻的非 passive `touchmove`，只有按住悬浮球拖动时才临时监听。

## 数据存储说明

- 以前版本把收藏存在浏览器 `localStorage` 里，只对当前设备有效。v1.1.0 起改为写入服务器端设置，并在首次加载时自动把本机旧数据合并进去，不会丢收藏。
- 手机和电脑各有一份旧数据时，两端都会在升级后的第一次加载时并入服务器数据（只合并一次）。
- 悬浮按钮的拖拽位置属于设备本地习惯，仍然只保存在各自设备的 `localStorage`，不参与跨设备同步。
- 建议定期用面板右上角的「导出」保存一份 JSON 到本地，作为额外保险。

## 拾遗
- **快捷收藏**：每条 AI 回复下方自动注入书签按钮，一键收录。
- **划词 / 划句收藏**：在页面正文里选中任意一段文字（鼠标拖动或手机长按），选区旁会浮出一个极简收藏按钮；只收录选中的那一段，而不是整层消息。
- **收藏即划线**：收录的那一段会在正文里显示暗红下划线，取消收藏（面板删除 / 再次选中该句）后下划线立刻消失；消息重绘、切换聊天后会自动补回。
- **再选即取消**：已收藏的句子再次被选中时，浮动按钮变成实心并提示「取消收录」，点一下即取消收录。
- **收藏去重（包含关系）**：只选长句里的一小段不会再多出一条——已收录的更长的句子包含本次选区时直接拦下；反过来，这次选得比旧条目长、并且完整包含了它时，把旧条目升级成这条长句，而不是新增一条。
- **点击划线即选中**：点一下正文里的下划线，会自动选中整句并浮出书签；必须再点书签才会取消收录，点划线本身不会删除任何收藏。
- **双 Tab 分类**：内置【当前聊天】与【全部聊天】切换，全部聊天自动按 `角色名 - 存档名` 折叠分组。
- **拾遗检索**：【当前聊天】支持按书签正文搜索，并按楼层 / 收藏时间升降序排序；【全部聊天】支持按书签正文、角色名、对话名搜索，并按角色筛选。
- **暗红呼吸特效**：在【当前聊天】点击语录，页面平滑跳转，并附带 2 秒的左侧档案条暗红呼吸高亮。
- **古籍风详情弹窗**：在【全部聊天】点击，弹出极简排版的无纸化详情卡片。
- **空状态**：当没有语录时，界面会展示中英双语现代诗（已适配手机端排版）。
- **拖拽**：悬浮球支持全端拖拽。

## 导出卡片
- **入口**：书签详情弹窗右上角新增「导出」图标（在关闭按钮左侧），点开即是导出浮层。
- **四套模板**（均为 1:1 方形卡片，导出 2160×2160 PNG）：
  - **档案馆**：原有拾遗详情样式，无头像，右下角 `—— {{user}} 摘` 落款。
  - **社媒**：顶部圆形头像 + 角色/对话名，中间方框正文（左对齐），底部互动栏（520 / 1314 / `<○●○>` / 999 为设计稿装饰，翻页点中间那颗实心表示当前页）与一行英文。
  - **信纸**：`To {{user}}` + 横格线（正文一行一格压在线上）+ 右下角色/时间落款 + 羽毛装饰。
  - **小报**：两张纸叠着——下面那张小一圈、转了 5°，四个角从上面那张底下露出来；上面那张有左上图钉、虚线标题框，标题下是一行「时间 / #楼层」加一条分隔线，左侧正文框，右侧头像（左上角贴 45° 胶带标签）与英文摘抄。
- **微调**：字号三档（小 / 中 / 大）、字体四款（宋体 / 楷体 / 黑体 / 等宽）、配色三块（纸色 / 墨色 / 强调色，可按模板分别保存）。配色用**自绘取色器**（色相条 + 明彩面 + 十六进制输入），安卓上不会再弹系统那个取色框。某个模板被单独改过色时会显示「已自定义」标记，点「恢复默认」即可回到主题色。
- **楷体可内置**：安卓原生没有楷体，默认会回退成宋体。把 `LXGWWenKaiLite-Regular.ttf`（霞鹜文楷 Lite，OFL 协议）放进 `fonts/` 目录，各设备就都用同一套楷体了 —— 见 [fonts/README.md](fonts/README.md)。没放这个文件也不报错，只是回退系统字体。
- **长文本**：自动逐级缩小字号把正文塞进版面；缩到下限仍放不下时末行截断加省略号，**不会生成长图**。真的被截断时，浮层里会多出一行提示（不画进图片）。
- **预览 / 保存**：预览图直接嵌在浮层内，微调页的小图**轻点即可放大**看细节；保存走浏览器下载（安卓 / 桌面都进下载目录，iOS 会新开图片页，长按可存相册），导出 2160×2160 PNG。
- **视口自适应**：手机上面板按 94vw 收紧，桌面 / 4K / 超宽屏按 `clamp()` 放大到 780px，不会出现「大屏小窗」。
- **头像来源**：按收藏记录的 `scope` 去 SillyTavern 角色数据里取（`/thumbnail`），同源绘制不会污染画布；取不到时退化为首字母圆牌。
- **实现**：独立文件 `export.js`，由 `index.js` 末尾一行 `import('./export.js')` 引入，不参与拾遗 / 档案馆的任何逻辑；`index.js` 不新增任何导出代码。

## 外观配色
- **入口**：酒馆「扩展」设置面板里的「ST-档案馆 · 外观」。
- **三块可调**：强调色 / 纸色 / 墨色，各带取色器和十六进制显示，另有 6 套预设（暗红 / 松绿 / 藏青 / 墨紫 / 茶褐 / 素灰）和一键恢复默认。取色器和导出面板共用同一个自绘组件（`color-picker.js`），手机上不会弹系统那个三滑块对话框。
- **实现**：所有写死的颜色都换成了 `var(--sa-accent)`、`rgba(var(--sa-accent-rgb), α)` 这类 CSS 变量（带原色兜底），改色即时生效、不必刷新。
- **默认零变化**：三色都取默认值时走的还是原来那套色值，视觉与上一版完全一致。
- **对比度提醒**：墨色与纸色对比度低于 3:1 时会提示，避免挑出看不清的组合。
- **强调色**作用于书签按钮、下划线、卡片封条、tab、详情标题、导出面板，以及**档案馆的左侧封条与行分隔线**——这些以前用的是酒馆主题边框色或写死的灰，换色时纹丝不动，现在统一跟着走。名字下面那条重复横线和检索台的虚线已经去掉（两根线挤在一起不好看）。
- **半透明底不动**：拾遗面板、详情弹窗、首页档案馆的底色是刻意做成「半透明 + 跟随酒馆主题」的，配色功能**不碰**它们。纸色 / 墨色只作用于导出浮层与导出卡片。
- **导出卡片也跟着走**：四套模板的默认配色继承这里的强调色 / 纸色 / 墨色，界面绿了卡片不会还是红的；在导出面板里给某个模板单独改过颜色，仍以单独设置为准，"恢复默认"会回到主题色。

## 剧情索引
- **魔杖菜单入口**：在魔杖菜单中注入「剧情索引」按钮，点击打开全屏索引。
- **左右气泡**：遍历当前 `chat`，每层楼截取去掉 HTML / 换行后的前 50 个字符；超过两行或超过 50 字时用省略号表示。Char 发言在左，User 发言在右，气泡外侧标注 `#楼层号`。
- **索引搜索**：标题下方提供拾遗同款极简搜索框，只搜索当前聊天正文；命中时以第一次出现的位置为中心截取 50 字并高亮关键词，前后按需补省略号。搜索结果按需异步分片加载，不会一次性扫描或渲染全部楼层。
- **点击跳转**：点击任意气泡，平滑滚动到对应楼层，并附带短暂呼吸高亮。
- **虚拟列表**：无论聊天有几百还是几千楼，DOM 中始终只保留视口附近的几十个气泡；预览文字也只在滚到附近时计算并缓存，打开面板不会一次性渲染几千个 `div`。

## 安装方法

### 方法一：酒馆一键安装（推荐）
1. 打开SillyTavern，点击顶部菜单的**“扩展”**。
2. 点击 **Install Extension**（安装扩展）。
3. 粘贴本仓库的链接，点击确认即可。

### 方法二：手动安装
将本仓库的 `manifest.json`、`index.js`、`style.css` 放入酒馆的 `public/scripts/extensions/third-party/ST-Archive` 目录下，重启酒馆。

## 叠甲
本扩展为作者根据个人喜好深度定制的 UI 扩展，代码撰写和测试均在pc端进行，不保证与所有酒馆版本/主题完美兼容，不提供任何技术支持，不定期更新。如果觉得好看并认为项目没有问题，欢迎使用。

## 兼容性与测试环境

本扩展已在以下环境完成深度兼容性测试，确保在手机与 PC 端都能获得极佳的 UI 体验：
- **酒馆版本**：SillyTavern v1.19.0
- **PC测试端**：Windows 11(配合 Edge浏览器)
- **移动测试端**：Android移动端(配合Edge浏览器)/局域网连接pc端(vivo浏览器)
- **UI主题适配**：原生亮暗色主题/各种复杂渲染的主题环境(仅限未改变SillyTavern原生UI位置的主题)

- 拾遗【全部聊天】新增搜索框 + 角色筛选：搜索范围覆盖书签正文、角色名、对话名。
- 检索栏为档案馆搜索/排序那一行的紧凑版，配色跟随拾遗暗红主题，并适配手机端。
- 重命名角色时自动迁移收藏的 scope/chatKey：当前聊天书签不再消失，全部聊天的 char 名同步更新。
- 删除角色时自动清理该角色的孤儿收藏：单层遍历 + `Set` O(1) 命中，不使用双层循环。
- 全部聊天筛选框固定三字宽，收起时只显示前三个字，下拉弹窗保留完整角色名。
- 检索栏改为无圆角、全透明背景、各自独立细下线，并去掉排序/筛选箭头。

- 正文书签/划线改为“事件驱动 + 只看可见消息 + 楼层索引”，移除每秒全量扫描。
- 下划线优先使用 CSS Custom Highlight API，正文零节点；老浏览器自动降级。
- 首页档案馆改为按页/按批懒渲染，翻页不再搬动所有角色组。

- 手机端移除常驻的非 passive `touchmove` 监听。
